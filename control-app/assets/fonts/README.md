# Bundled fonts

Both families are bundled rather than fetched at runtime so the console renders correctly when
the network is the thing that is broken.

| Family | Source | Licence |
|---|---|---|
| Chakra Petch | [google/fonts](https://github.com/google/fonts/tree/main/ofl/chakrapetch) | SIL Open Font License 1.1 — `OFL-ChakraPetch.txt` |
| IBM Plex Mono | [google/fonts](https://github.com/google/fonts/tree/main/ofl/ibmplexmono) | SIL Open Font License 1.1 — `OFL-IBMPlexMono.txt` |
